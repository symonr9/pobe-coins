# @pobe/mobile

@AGENTS.md

## This project

- Routes are in `src/app/` (Expo Router, typed routes). Tabs use `expo-router/js-tabs` with a custom `TabBar`, which becomes a labelled `SideRail` at 900px and up (`useWide()`).
- UI kit in `src/ui/`:
  - `Text` variants: hero, h1–h3, title, body, small, smallBold, label, number.
  - `Button`, `Pressy` (press-scale + haptics), `Card`, `Row`, `Stack`, `Section`.
  - `Screen` (safe areas, pull-to-refresh, `wide` for dashboards), `Columns` (two columns on wide screens).
  - `Field`/`Segmented`/`ListRow`, `Coins`, `Icon`, `bits` (EmptyState, ProgressRing, Sheet, Avatar), `Feedback` (toast/confirm).
- Theme: `useTheme()` gives `.c` colors, `.fonts` and so on. Tokens come from `@pobe/core` `THEMES`. The font is Plus Jakarta Sans.
- Data: TanStack Query hooks and `actions` are in `src/api/hooks.ts`. The client in `src/api/client.ts` handles auth headers and token refresh.
- Features:
  - `src/features/`: `chubby/` (the `Chubby` component and `say()`), `celebrate`, `spending` (IOU/change preview + biometrics), `tasks`, `timeline`.
  - `src/widgets/`: iOS `expo-widgets`, Android `react-native-android-widget`.
- i18n: wrap copy in `t('English text')`, then run `npm run i18n:extract -w @pobe/mobile` to update `locales/en.json`.
- Commissioned Chubbybara art goes in `src/features/chubby/assets.ts`. Icons are generated by `scripts/make-assets.ts`.

## Sandbox notes (overrides AGENTS.md where they conflict)

- If `npx expo install` can't reach Expo's API (cloud sandbox), add packages with `npx -y npm@11.20.0 install <pkg>@<version> -w @pobe/mobile`, taking the version from `node_modules/expo/bundledNativeModules.json`.
- Verify UI with `npm run screens` (repo root) and look at the PNGs; typecheck alone doesn't show layout bugs.
